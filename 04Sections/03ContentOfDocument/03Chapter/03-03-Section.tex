Una vez finalizado el desarrollo del \textit{middleware} y en base al trabajo realizado, se plantean las siguientes recomendaciones que permitirán fortalecer y ampliar las caracterísiticas del producto software realizado. 

\begin{itemize}
    \item Para mejorar el método de trabajo se recomienda la inversión en la capacitación de los miembros del equipo sobre tecnologías emergentes y otros conocimientos que aumenten su productividad y rendimiento, además de fomentar un ambiente comunicativo que permita tener una visión más amplia y clara del desafío de negocio, mismo que ayudará a realizar un análisis riguroso y detallado durante la toma de decisiones al construir un producto.
    \item Para el uso de conexiones muy frecuentes a bases de datos, se recomienda la  implementación para seleccionar una base de datos como predeterminada, con esto se evita la búsqueda y selección de forma manual en reiteradas ocasiones, aumentando la familiaridad e interés de uso de los usuarios.
    \item También se recomienda la extensión de la gramática SQL soportada para la traducción, incluyendo operaciones DDL útil para el manejo completo de tablas y esquemas dentro de las bases de datos SQL, mismos que son útiles para un control total de los datos dentro de una base de datos.
    \item Debido a su fácil integración tanto con bases de datos relacionales como oreintadas a grafos, se recomienda la inclusión de otros dialectos y la compatibilidad con otros DBMS como Postgres, MySQL, Amazon Neptune o ArangoDB.
    \item Se recomienda la implementación de pruebas de estrés que permitan identificar posibles cuellos de botella durante el proceso de traducción y ejecución de consultas, además del renderizado de resultados a grafos.
\end{itemize}
