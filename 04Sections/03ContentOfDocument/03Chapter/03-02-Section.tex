El presente Trabajo de Integración Curricular (TIC) permitió llevar a cabo un trabajo que involucra cada una de las etapas de desarrollo de software desde la investigación inicial hasta la implementación del \textit{middleware} y validación del sistema construido.

Durante la investigación para la traducción de bases de datos relacionales a bases de datos oreintadas a grafos, se pudo conocer más a detalle las características y ventajas que estas últimas presentan dado la velocidad y precisión que brinda en la consulta de datos que presenten relaciones complejas.

Así mismo, la elección de una metodología ágil en conjunto de un marco de trabajo como Scrum, permitió una construcción incremental del sistema y de manera ágil, que permitió adaptar sin mayor dificultad los cambios que iban surgiendo a lo largo del proyecto.

La separación clara entre el \textit{frontend} y el \textit{backend} durante el diseño de la arquitectura del sistema, permite que el código pueda ser altamente escalable y mantenible, lo cual es para la integración con bibliotecas externas y otras bases de datos en versiones futuras.

Durante la etapa de desarrollo, la implementación de librerías dedicadas a la conexión a bases de datos así como al parseo de de sintaxis SQL facilitó que la aplicación soporte una gramática extensa del lenguaje SQL incluyendo todas las operaciones DML, cláusulas como JOIN, ORDER BY, HAVING y funciones de agregación como COUNT o SUM. Esto añadido a la fácil integración con DBMS como SQL Server y Neo4j, resultaron en el desarrollo de un motor de traducción bastante robusto y capaz de ejecutar sentencias Cypher traducidas en una base de datos Neo4j sin mayor complejidad.

Tanto los resultados de las pruebas funcionales como las pruebas de usabilidad demostraron la integración de los componenntes del sistema para producto que satisfaga las necesidades de los usuarios de una manera atractiva y familiar. Así también, con la retroalimentación adquirida, se pueden identificar áreas de mejora que permitirán optimizar el sistema en versiones futuras.

El proyecto no solo cumplió con los objetivos planteados inicialmente sino que también aportó un aprendizaje valioso en cuanto a la traducción de bases de datos orientadas a grafos, la gestión y construcción de un producto software. La integración entre metodologías de trabajo, herramientas y conocimientos técnicos garantizan un resultado exitoso y adaptable ante las demandas cambiantes dentro del software moderno.
