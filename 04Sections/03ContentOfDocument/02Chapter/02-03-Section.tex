\subparagraph{Cifrado de contraseñas y manejo de sesiones:} 
En el servicio de autenticación, se implementó el algoritmo Bcrypt para hashear la contraseña del usuario previo a ser almacenada.

    def get_password_hash(password):
        pwd_bytes = password.encode("utf-8")
        salt = bcrypt.gensalt()
        hashed = bcrypt.hashpw(pwd_bytes, salt)
    return hashed.decode("utf-8")
\end{lstlisting}

Por su parte, para el manejo de sesiones se utilizó JWT, mismo que genera tokens que contiene información del usuario cifrada y un tiempo de expiración. El tiempo de caducidad del token está configurado para 15 minutos y la firma para generación de tokens se obtiene de las variables de entorno con lo cual se refuerza la seguridad del software.

\begin{lstlisting}[language=Python]
    def create_access_token(data: dict, expires_delta: Optional[timedelta]):
        to_encode = data.copy()
        if expires_delta:
            expire = datetime.now() + expires_delta
        else:
            expire = datetime.now() + timedelta(minutes=15)

        to_encode.update({"exp": expire})
        encoded_jwt = jwt.encode(to_encode, JWT_SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt
\end{lstlisting}

\begin{lstlisting}[language=Python]
    class SelectHandler(BaseHandler):
        def handle(self, expression: exp.Select) -> str:
            match_clause = self._build_match(expression)
            where_clause = self.build_where(expression)
            return_clause = self._build_return(expression)

            order_clause = self._build_order_by(expression)
            limit_clause = self._build_limit(expression)

            parts = [match_clause, where_clause, return_clause, order_clause, limit_clause]
            return " ".join([p for p in parts if p]).strip()
\end{lstlisting}

\subparagraph{Implementación de ejecución de consultas:}
Con ayuda de la biblioteca \texttt{neo4j}, se implementó el ejecutor de consultas Cypher. Una vez que se ha traducido una consulta SQL, dicho resultado se ejecuta directamente hacia la base de datos Neo4j. El siguiente fragmento de código indica el proceso para interactuar con una base de datos en Neo4j. Primero, se crea una conexión hacia la base de datos objetivo, se traduce la consulta y se procesa la respuesta, devolviendo el resultado de la ejecución para ser utilizado en el backend.

\begin{lstlisting}[language=Python]
    class Neo4jExecutor:
        def execute(self, query: str) -> Dict[str, Any]:
            nodes = {}
            links = []
            with self.driver.session() as session:
                result = session.run(query)
                for record in result:
                    for key, value in record.items():
                        if hasattr(value, "labels"):
                            node_id = str(value.element_id or value.id)
                            if node_id not in nodes:
                                nodes[node_id] = {"id": node_id, "labels": list(value.labels), "properties": dict(value._properties)}
                        elif hasattr(value, "start_node"):  # Relación
                            links.append({"source": str(value.start_node.element_id or value.start_node.id), "target": str(value.end_node.element_id or value.end_node.id), "type": value.type, "properties": dict(value._properties)})
            return {"nodes": list(nodes.values()), "links": links}
\end{lstlisting}

\subparagraph{Traducción de DML (INSERT, UPDATE, DELETE):}
Finalmente, se extendió la gramática para soportar las sentencias de manipulación de datos.
\begin{itemize}
    \item \texttt{INSERT INTO}: Se traduce a una sentencia \texttt{CREATE} en Cypher para crear un nuevo nodo con las propiedades especificadas.
    \item \texttt{UPDATE}: Se mapea a una combinación de \texttt{MATCH} y \texttt{SET} para encontrar los nodos a actualizar y modificar sus propiedades.
    \item \texttt{DELETE}: Se convierte en una sentencia \texttt{MATCH} seguida de \texttt{DETACH DELETE} para eliminar los nodos y sus relaciones asociadas.
\end{itemize}

\begin{figure}[H]
    \centering
    \begin{lstlisting}[language=Python]
# app/core/parser/visitor.py
class Visitor(SQLSimpleVisitor):
    # ... (metodos existentes) ...

    def visitInsert_statement(self, ctx: SQLSimpleParser.Insert_statementContext):
        # Logica para traducir INSERT a CREATE
        return "CREATE (n:Label {key: 'value'})"

    def visitUpdate_statement(self, ctx: SQLSimpleParser.Update_statementContext):
        # Logica para traducir UPDATE a MATCH y SET
        return "MATCH (n:Label WHERE n.id = 1) SET n.property = 'new_value'"

    def visitDelete_statement(self, ctx: SQLSimpleParser.Delete_statementContext):
        # Logica para traducir DELETE a MATCH y DETACH DELETE
        return "MATCH (n:Label WHERE n.id = 1) DETACH DELETE n"

    \item \textbf{¿Qué se puede mejorar?} \newline
    El sistema de envío de correos electrónicos es funcional, pero podría beneficiarse del uso de plantillas HTML para que los correos sean más atractivos y profesionales. En la gestión de usuarios, se podría añadir una funcionalidad de búsqueda y filtrado para que los administradores puedan encontrar usuarios más fácilmente. La auditoría de acciones de administrador (quién hizo qué y cuándo) sería una adición valiosa para la seguridad y el monitoreo.
    
\end{itemize}
